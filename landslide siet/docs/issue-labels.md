# Issue Labels

Create these labels in the GitHub repository settings. They are guidance only;
no repository label automation is configured.

| Label | Purpose |
| --- | --- |
| `bug` | Reproducible defect |
| `feature` | New product behavior |
| `backend` | FastAPI or persistence work |
| `frontend` | Next.js UI or accessibility work |
| `data` | Data source, ingestion, or provenance work |
| `ml` | Training, evaluation, or inference work |
| `docs` | Documentation or onboarding |
| `security` | Credential, authorization, or dependency concern |
| `needs-review` | Needs domain, data-license, or operational review |
| `demo-only` | Demonstration behavior not intended for emergency use |
| `good first issue` | Bounded contribution suitable for a newcomer |
